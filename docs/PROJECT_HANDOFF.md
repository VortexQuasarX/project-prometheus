## 1. Executive Summary

**What it is:** Project Prometheus is an Agentic AI Governance and FinOps
Control Plane — an LLM gateway that routes, caches, retrieves, evaluates,
governs, observes, and optimizes LLM usage while generating auditable
cost-saving actions. Backend: FastAPI (Python 3.11). Frontend: Next.js 14
App Router dashboard (12 pages). Local persistence: SQLite (WAL). Providers:
swappable (mock | openai-compatible | bedrock). Infra-as-code: Terraform
(cost-gated). CI: GitHub Actions (lint + tests + security scans + frontend +
Docker builds).

**Problem it solves:** teams adopting LLMs face unpredictable token costs,
repeated queries, no model routing, no governance, no observability, unsafe
prompts, and no FinOps loop. Prometheus treats cost, quality, and policy as
pipeline stages.

**Target users:** AI platform teams, FinOps teams, engineering orgs adopting
LLMs; recruiters/interviewers evaluating the builder.

**Main capabilities:** 12-step chat pipeline (auth → rate limit → budget →
guardrails → router → semantic cache → RAG → LLM → evaluator → cost → audit),
semantic cache with savings accounting, 6-role RBAC + multi-tenancy,
FinOps agent with human-approval gate, policy engine (versioned + audited),
eval harness, Prometheus/OTel observability, Kafka-style event pipeline,
MLOps lifecycle (distillation training, MLflow, PSI drift, safe retraining).

**Current maturity:** production-oriented MVP. All core functionality is
implemented and locally verified (79/79 tests). AI/LLM layer is real-code but
runs on the mock provider unless an API key is configured (by original spec:
mock-first, no paid APIs required). Cloud deployment is code-complete but not
applied (spec: explicit APPLY only).

**What is actually working today (VERIFIED):** backend + frontend build and
run; 79/79 tests; ruff clean; CI fully green on GitHub (including bandit,
pip-audit, both Docker images); live end-to-end chat with cache-hit savings,
traces, guardrails, FinOps agent approval flow verified earlier against
running servers. Servers are currently DOWN (background processes do not
survive machine sleep; restart commands in §26).

## 3. Architecture

Frontend (Next.js, port 3000) → same-origin rewrite `/api/v1` → FastAPI API
(port 8000) → pipeline: auth (X-API-Key, SHA-256) → RBAC → rate limit
(sliding window; IP fallback) → budget/kill-switch → guardrails (PII
mask/block) → Router Agent (heuristic; learned model available) → semantic
cache (hash embeddings, cosine ≥ 0.82, versioned) → RAG retriever (local
vector store JSONL; pgvector path) → LLM provider (mock | openai-compatible |
bedrock) → evaluator → cost tracker → audit (append-only) → response.
Observability: 12 trace events/request + SSE transactional outbox +
Prometheus /metrics + OTel spans. Event pipeline: Kafka-style
producer/consumer groups/DLQ. ML: distillation training → MLflow → drift →
promotion-gated retraining → inference service.

```
Next.js (3000) ──/api/v1──► FastAPI (8000)
                               │
   ┌───────────┬───────────────┼────────────────┬──────────────┐
   ▼           ▼               ▼                ▼              ▼
 Auth/RBAC  Rate limiter   Guardrails      Router agent    Semantic cache
   │           │               │                │              │
   └───────────┴───────┬───────┴────────────────┘              │
                       ▼                                       │
                 RAG retriever ──► LLM provider ──► Evaluator   │
                       │                 (mock/openai/bedrock)  │
                       ▼                                        ▼
                 Cost tracker ◄────────────────────────── savings
                       │
   ┌───────────────────┼───────────────────────────┐
   ▼                   ▼                           ▼
 SQLite (WAL)   trace events (12)          audit (append-only)
   │                                              │
   ▼                                              ▼
 SSE outbox ──► /events/stream          Kafka-style events ──► DLQ
 ML: train (MLflow) → drift (PSI) → retrain (gate) → inference svc (8100)
```
